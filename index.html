The loop

Build

A 3D hangar builder. Drag parts, stack hull, bolt on guns, engines and cargo. Every ship in the game is built from the same parts.

Fly & fight

Third-person flight with boost, cruise drive, missiles and gatlings. Sectors get more dangerous the further out you go.

Earn

Take contracts at stations, haul cargo, mine asteroid fields and trade between sectors. Hire crew who level up.

Go further

Jump across the galaxy to more dangerous, better-paying sectors, with autopilot and a tactical nav table.

Install notes

Windows

Unzip the whole folder and run the .exe inside. If SmartScreen says "Windows protected your PC", click More info → Run anyway.

macOS

Unzip and drag the app to Applications. It isn't notarized yet, so the first launch is blocked. Open System Settings → Privacy & Security, scroll down and click Open Anyway. Runs on Apple Silicon and Intel.

It's early

These are dev builds: expect rough edges and save wipes between versions. Press H in game for the controls.
